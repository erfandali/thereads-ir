# 📄 مستند فنی پروژه Flutter – ادعا (Thereads-IR)

## 🧾 معرفی پروژه

**ادعا** یک اپلیکیشن موبایل اجتماعی است که از نظر عملکرد شباهت زیادی به اپلیکیشن [Threads by Instagram](https://www.threads.net/) دارد. کاربران می‌توانند پست ادعا کنند، تعامل اجتماعی داشته باشند، و محتوای دیگر کاربران را مشاهده کنند. این پروژه با Flutter توسعه داده شده و در حال حاضر در مرحله توسعه (branch: `develop`) قرار دارد.

کارفرمای پروژه: **آقای حمودی**  
توسعه‌دهنده فعلی: [erfandali](https://github.com/erfandali)

---

## ⚙️ پیش‌نیازهای اجرای پروژه

برای اجرا و توسعه پروژه به ابزارهای زیر نیاز دارید:

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (نسخه پیشنهادی: 3.10+)
- Android Studio یا VS Code
- شبیه‌ساز اندروید یا دستگاه واقعی
- حساب کاربری برای سرویس‌های پشتیبان (در صورت استفاده از APIهای خارجی یا Firebase)
